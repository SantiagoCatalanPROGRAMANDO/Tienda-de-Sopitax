# TIENDA DE TCG DE SOPITAX

## Descripción del proyecto

Tienda de TCG de Sopitax es un sitio web desarrollado con HTML5 que presenta una tienda dedicada a productos relacionados con los juegos de cartas coleccionables o TCG, su abreviación.

El proyecto está organizado en diferentes páginas para facilitar la navegación y ofrecer información sobre la tienda, sus productos y sus medios de contacto.

## Estructura de carpetas

El proyecto está organizado de la siguiente manera:

```text
Tienda-de-Sopitax/
│
├── mi-proyecto/
│   ├── index.html
│   │
│   ├── pages/
│   │   ├── contacto.html
│   │   ├── faq.html
│   │   ├── historia.html
│   │   └── productos.html
│   │
│   └── assets/
│       ├── logo.jpg
│       ├── historia.jpg
│       ├── productos.jpg
│       ├── telefijo.jpg
│       └── faq.jpg
│
└── README.md
```

## Herramientas que utilicé

- HTML5.
- Etiquetas semánticas.
- Estructura de navegación mediante listas y enlaces.
- Imágenes incorporadas mediante la etiqueta `img`.
- Git y GitHub para el control de versiones.

## Páginas del sitio

- **Inicio:** página principal de la tienda.
- **Historia:** información sobre la historia de la tienda.
- **Productos:** presentación de los productos.
- **Contacto:** información y medios de contacto.
- **Preguntas frecuentes:** respuestas a consultas habituales.

## Recursos visuales

Las imágenes utilizadas están dentro de la carpeta `assets/`.

## Cómo visualizar el proyecto localmente

1. Descargar el repositorio desde GitHub mediante la opción **Code → Download ZIP**.
2. Extraer el archivo ZIP.
3. Abrir la carpeta `mi-proyecto`.
4. Ejecutar el archivo `index.html` en un navegador web.
5. Utilizar el menú de navegación para acceder a las diferentes páginas.
